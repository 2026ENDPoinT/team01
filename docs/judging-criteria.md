## 참가자 평가 (인기투표 · 15점)

| 항목 | 내용 |
|---|---|
| 방식 | 1인 3표, 좋았던 팀 3곳에 1표씩. 한 팀에 중복 투표 불가 · 자기 팀 투표 불가 |
| 투표 시점 | 트랙별 발표가 모두 끝난 직후 1회. 참가자 전원이 두 트랙 모두 투표 |
| 점수 | 아래 식으로 **트랙별로 따로** 계산 |

```
P_i = 15 × √( min(1, v_i / (2 × v̄)) ),   v̄ = V / N
```

- v_i: i팀의 득표수, V: 그 트랙에서 나온 전체 표 수, N: 그 트랙의 팀 수, v̄: 팀당 평균 득표
- **평균의 2배 이상**을 받으면 만점(15점)입니다. 표가 한 팀에 몰려도 그 팀은 15점에서 멈추고, 1위 팀이 몇 표를 받았는지는 다른 팀 점수에 영향을 주지 않습니다.
- 제곱근을 쓰기 때문에 적게 받은 팀일수록 한 표의 가치가 커서, 표 쏘림으로 생기는 점수 차가 줄어듭니다.

예시: 10팀 트랙, 60명 투표 (전체 180표, 평균 18표, 만점 기준 36표)

| 득표 | 새 방식 (15점) | 이전 방식 (1위 80표일 때, 25점) |
|---|---|---|
| 80 | 15.00 | 25.00 |
| 36 | 15.00 | 11.25 |
| 27 | 12.99 | 8.44 |
| 18 | 10.61 | 5.63 |
| 9 | 7.50 | 2.81 |
| 3 | 4.33 | 0.94 |
| 0 | 0.00 | 0.00 |

## 점수 합산

```
S_i = 0.85 × J_i + P_i      (100 = 85 + 15)
```

| 항목 | 내용 |
|---|---|
| 최종 점수 S_i | 심사위원 점수 × 0.85 + 참가자 점수 |
| 심사위원 점수 J_i | 심사위원 원점수(100점 만점)의 평균 |
| 참가자 점수 P_i | 위 식, 15점 만점 |
| 동점 처리 | 심사위원 점수 → 구조적 이해 점수 순 |

# 구현과제 필수 기능 (성적 관리 소프트웨어)

## 필수 구현 기능 (5개 항목 · 모두 구현 필수)

| # | 항목 | 내용 | 비고 |
|---|---|---|---|
| ① | 과목·성적 등록 | 과목명, 수강 학기, 학점 수, 성적 등급을 입력해 과목을 등록 | 예) 자료구조 · 2026년 1학기 · 3학점 · A+ |
| ② | 과목 조회·관리 | 등록한 과목과 성적을 목록으로 조회하고 수정·삭제 | 학기별로 과목을 구분해 표시 |
| ③ | 평점평균(GPA) 자동 계산 | 학기별 평점평균, 전체 누적 평점평균, 학기별·전체 등록 학점 수 표시 | 4.5 만점 체계 · 결과는 소수점 둘째 자리까지 |
| ④ | 데이터 저장·불러오기 | 새로고침하거나 프로그램을 재실행해도 기존 데이터를 확인 | LocalStorage, JSON 파일, SQLite 등 자유 선택 · 로그인·서버 구축 필수 아님 |
| ⑤ | 기본 예외 처리 | 잘못된 입력이나 상황을 적절히 처리 | 과목명 미입력 · 학점 수가 0 이하이거나 숫자가 아님 · 지원하지 않는 성적 등급 · 등록된 과목 없이 평점평균 조회 |

필수 기능 5개를 모두 구현한 팀은 자유롭게 선택 기능을 추가할 수 있습니다.
